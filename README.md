# Kanjigation Quest!
こんにちは！
This is a project that I made in my spare time to help polish up on various aspects of the Japanese language. Supports many aspects of studying basic Japanese using the GENKI textbook as a baseline.
- Expressions, Vocabulary, and Grammar
- Word Conjugation
- Reading and writing numbers
- KoSoADo
- More coming soon!

**Adventure Mode**: fight monsters by successfully completing conjugation tasks. Can you beat the ラスボス?
